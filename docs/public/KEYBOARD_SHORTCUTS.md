# Keyboard shortcuts

Every shortcut below is the default. **All of them can be changed** in Settings ▸ Keyboard, which
lists the same actions and takes effect straight away — no relaunch.

Shortcuts are written for macOS. On Windows and Linux, **⌘ is Ctrl**; ⌥ is Alt and ⌫ is Backspace.

## File

| Action | Shortcut |
|---|---|
| New Window | ⌘N |
| New Tab | ⌘T |
| New Folder | ⇧⌘N |
| New File | *unassigned* |
| Close Tab | ⌘W |
| Close Window | ⇧⌘W |
| Show Previous Tab | ⌥⌘← |
| Show Next Tab | ⌥⌘→ |
| Switch to tab 1–9 | ⌘1 – ⌘9 |
| Get Info | ⌘I |
| Reveal in Finder | ⇧⌘R |
| Open in Terminal | ⌥⌘T |
| Extract | *unassigned* |
| Delete Application… | *unassigned* |
| Settings | ⌘, |
| Quit | ⌘Q |

*Quit is the one shortcut that can't be reassigned — macOS decides what ⌘Q means.*

## Edit

| Action | Shortcut |
|---|---|
| Undo | ⌘Z |
| Copy | ⌘C |
| Cut | ⌘X |
| Paste | ⌘V |
| Copy Path | ⌥⌘C |
| Select All | ⌘A |
| Rename | F2 |
| Duplicate | ⌘D |
| Move to Trash | ⌘⌫ |
| Delete Immediately… | ⌥⌘⌫ |

*Undo puts back the last move or Move to Trash, all of it or none of it. A permanent delete offers
none — there is nothing to put back.*

## View

| Action | Shortcut |
|---|---|
| as Icons | ⌥1 |
| as List | ⌥2 |
| Bigger Text | ⌘+ |
| Smaller Text | ⌘- |
| Actual Size | ⌘0 |
| Show/Hide Sidebar | ⌥⌘S |
| Show/Hide Hidden Files | ⇧⌘. |
| Refresh | ⌘R |

*⌘+ is Shift and = on most layouts, which is why Settings ▸ Keyboard writes it as ⇧⌘= — the
same keys. ⌘= on its own and the numeric keypad's + work too.*

## Go

| Action | Shortcut |
|---|---|
| Back | ⌘[ |
| Forward | ⌘] |
| Enclosing Folder | ⌘↑ |
| Quick Open… | ⌘/ |
| Go to Folder… | ⇧⌘G |
| Connect to Server… | ⌘K |

*Quick Open is one field that reaches every favorite, volume, server and attached device, every
application on the machine, and every command in the menus — without going to find which menu it's
under. It lists nothing until you type.*

## File list

These belong to the file list and the icon grid while one of them has focus.

| Action | Shortcut |
|---|---|
| Move Up | ↑ |
| Move Down | ↓ |
| First Item | ⌥↑ |
| Last Item | ⌥↓ |
| Page Up | Page Up |
| Page Down | Page Down |
| Expand Folder | → |
| Collapse Folder | ← |
| Open Selection | Return |
| Quick Look | Space |
| Find | ⌘F |

*Hold ⇧ with any of the six movement keys to extend the selection instead of replacing it. In icon
view, where there is no outline to disclose, ← and → step one tile sideways. Home and End work
wherever a keyboard has them.*

*Type any letter to jump to the next item starting with it.*

## Open With

Any application on this machine can be given a shortcut of its own, which opens the selected files
with it. They're listed under **Open With** in Settings ▸ Keyboard, and none is assigned by default.

## Escape

Escape isn't bindable, because it means the same thing everywhere: back out. It cancels a dialog, a
rename, an open preview, and then the selection.
